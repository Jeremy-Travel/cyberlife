# CYBERLIFE — 赛博人生模拟器

一个无需安装、无需 API Key 的浏览器小游戏原型：你扮演城市背后的变量，干预居民的金钱、关系、事业与城市混乱度，观察他们自己生活下去。

## 立即开始
1. 解压本项目。
2. 双击 `index.html`，用 Chrome / Edge / Firefox 打开。
3. 点击「推进一天」，观察居民自主变化；再使用 God Mode 干预命运。
4. 「保存进度」会将存档保存在当前浏览器的 `localStorage` 中。

## 当前功能
- 6 位具有职业、资金、情绪与个人关系的居民
- 按天推进的自主模拟与随机事件
- 6 种上帝模式干预：横财、红线、爆红、传闻、派对、黑入系统
- 城市情绪、混乱度、繁荣度仪表盘
- 本地存档；无需网络、服务端或 API Key

目前是单文件 HTML/CSS/JavaScript 原型，方便快速体验和修改。居民行为由本地规则随机驱动，不是 AI，也不会把数据发送到外部服务。
